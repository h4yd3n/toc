🚧 UNDER CONSTRUCTION · WE HAVEN'T BUILT THIS YET

MODTOC is under construction.

We haven't built out the MODTOC engine or GUI yet — it is currently an open-source RFC and specification. Born from years leading integrity operations and coordinated inauthentic behavior (CIB) at TikTok, MODTOC is being designed to bring policy-as-code evaluations (make diff), severity × reach queue gating, and hash-chained audit trails to platform safety teams. We are looking for practitioners and engineers to collaborate with us.

The FLASH Warning DOCTRINE

A single critical alarm strip across all screens. Releases simultaneously over SMS and chat (simulated or Twilio/Slack) and demands verified sign-off.

⏱️

Automated roll-call accountability. Unresponsive personnel float to the top after 15 minutes, triggering escalation procedures automatically.

🛡️

The incoming watch officer must review and individually acknowledge every incident and intelligence shift that occurred during the handover overlap.

🔗

Every status change, radio report, and command decision is stored in an immutable, cryptographically chained audit log for post-incident review.

📱

The same operations wall rendered natively on mobile devices. Full offline cache, push check-ins, and biometric role authorization.

01
Separate Source Reliability & Analytic Confidence

Never blend them into an opaque machine score. Humans make the call; machines gather the signal.

02
Brief What Would Have to be True to be Wrong

Every assessment includes alternative hypotheses and indicators that would falsify the current read.

03
Hand Over on the Record

No loose shift handoffs. Incoming officers acknowledge the delta so accountability never lapses.

OPEN SOURCE RUNTIME

Up and Running in 60 Seconds

bash — toc-quickstart NO API KEYS NEEDED TO START 
# 1. Clone repository
git clone https://github.com/h4yd3n/toc.git && cd toc

# 2. Run test suite
make test

# 3. Launch COPTOC (FastAPI backend on :8000 + React Wall on :5173)
make run-cop

# 4. (Optional) Run SIGTOC standalone on :8002
make run-s2

# 5. (Optional) Run MODTOC Content Moderation Engine on :8001
make run-mod
